# liblyron_projectm (só a biblioteca nativa)

1. Suba esta pasta inteira para um repositório no GitHub.
2. Aba Actions > "Compilar liblyron_projectm.so" > Run workflow.
3. Ao terminar, baixe os 3 artifacts (jniLibs-arm64-v8a, jniLibs-armeabi-v7a, jniLibs-x86_64)
   e copie cada pasta de ABI para app/src/main/jniLibs/ do app.
